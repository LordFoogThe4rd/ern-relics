# Screenshot sources and usage terms

These six in-game screenshots were supplied by the project maintainer on
2026-11-06. The 2560 x 1440 PNG captures were resized to 1920 x 1080 with Pillow's
Lanczos filter and encoded as WebP at quality 90 with compression method 6.
The six WebP files total about 1.88 MB, down from 29.25 MB of PNG captures.
Keep original captures outside the repository. These images use ordinary Git.

| File | Content |
|---|---|
| [effect-search-and-draft.webp](effect-search-and-draft.webp) | Effect search and a pending replacement, with the change comparison visible |
| [effects-applied.webp](effects-applied.webp) | Confirmation after applying a character skill effect |
| [starting-armament-draft.webp](starting-armament-draft.webp) | Fire damage staged as a starting armament effect |
| [starting-armament-applied.webp](starting-armament-applied.webp) | Applied fire damage effect and its icon in the equipment screen |
| [presets.webp](presets.webp) | A saved preset with six normal and Deep Relic templates |
| [expedition-read-only.webp](expedition-read-only.webp) | Equipped relics during an expedition, where editing is unavailable |

The images document ERN Relics running in Elden Ring Nightreign. Game imagery
belongs to its respective rights holders, including FromSoftware and Bandai
Namco, and is not licensed under the project's MIT license. Sharing is subject
to the [Bandai Namco Entertainment Video Policy](https://static.bandainamcoent.eu/content/BANDAI_NAMCO_Entertainment_Video_Policy_%2820220124%29.pdf),
which covers gameplay screenshots for non-commercial fan use and does not
transfer ownership of game content. The policy was checked on 2026-11-06.

These are documentation images, not extracted game assets. They are not included
in mod packages. This community project is unaffiliated with FromSoftware and
Bandai Namco.

For Nexus Mods gallery uploads, create JPEG copies outside version control, such
as in `dist/nexus-screenshots/`. Keep the WebP files here as the repository copies.
